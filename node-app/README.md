## 2. Документація по розробленому веб-застосунку

### Призначення
Застосунок являє собою REST API сервіс для створення та зберігання текстових нотаток. Об'єкт нотатки містить поля `id`, `title`, `content` та `created_at`. Застосунок підтримує повернення даних як у форматі JSON, так і у вигляді простих HTML-таблиць залежно від заголовка `Accept`.

### Налаштування середовища та запуск (локально для розробки)
1. Переконатися, що встановлено Node.js (v20+) та PostgreSQL.
2. Склонувати репозиторій та перейти до папки проєкту.
3. Виконати встановлення залежностей:
   ```bash
   npm install
   ```
4. Налаштувати підключення до БД у файлі `config.json` або через `DATABASE_URL`.
5. Застосувати міграції: `npx prisma migrate dev`.
6. Запустити сервер: `npm start`.

### Запуск за допомогою Docker (Лабораторна робота №2)

Застосунок повністю контейнеризовано за допомогою Docker та Docker Compose. Інфраструктура складається з 3 сервісів:
1. **webapp** — Node.js застосунок (порт 5000)
2. **db** — PostgreSQL база даних (із збереженням даних у named volume)
3. **nginx** — Reverse proxy, який слухає на порту 80 і перенаправляє запити на webapp

**Як запустити:**
1. Встановіть [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Перейдіть у корінь проєкту:
   ```bash
   cd mywebapp
   ```
3. Запустіть контейнери:
   ```bash
   docker compose up -d
   ```
4. Відкрийте у браузері [http://localhost](http://localhost) або [http://localhost/notes](http://localhost/notes).

**Як зупинити:**
- Зберегти дані: `docker compose down`
- Видалити базу даних: `docker compose down -v`
